# Репетиционный FAQ-бот

Небольшой консольный бот для пяти частых вопросов о репетиции. Он не использует
RAG или внешние сервисы: ответы и ключевые слова лежат в `faq.txt`, а программа
сравнивает ключевые слова в вопросе пользователя с ключевыми словами каждого
FAQ-пункта.

## Запуск

Нужен Python 3.10 или новее. Дополнительных библиотек устанавливать не нужно.

```bash
python main.py
```

Введите вопрос и нажмите Enter. Чтобы закончить работу, введите `выход`, `exit`
или `quit`.

## Что получилось

В `faq.txt` есть пять пар вопрос–ответ: про время, команду, трек, сдачу и
призы. Бот выбирает запись с наибольшим числом совпавших ключевых слов. Если
ключевых слов нет, он честно отвечает: «Не знаю.»

Файл `faq.txt` легко менять: у каждой записи должны быть поля `Вопрос`,
`Ключевые слова` и `Ответ`, а записи разделяются строкой `---`.
